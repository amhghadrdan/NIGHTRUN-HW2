NIGHTRUN
امیرحسین قدردان ـ ۴۰۱۵۲۱۴۸۹
تمرین دوم طراحی بازی‌های کامپیوتری

بازی رانندگی بی‌نهایت در یک بزرگراه سه‌لاین با نمای سوم‌شخص و محیط شبانه.
ماشین خودکار جلو می‌رود. بازیکن باید از ترافیک رد شود، سکه و سوخت جمع کند
و رکورد بالاتری بزند. سه برخورد یا تمام شدن سوخت، راند را تمام می‌کند.

کنترل‌ها

A و D یا فلش چپ و راست: جابه‌جایی بین لاین‌ها
نگه داشتن Shift: نیترو
Escape: توقف، ادامه یا برگشت
فلش‌ها یا W و S: حرکت در منو
Enter یا Space: انتخاب گزینه
موس: دکمه‌ها و تنظیم صدا

نیترو سرعت را ۲۵٪ و مصرف سوخت را ۵۰٪ بیشتر می‌کند. شارژ آن پس از ۱٫۵ ثانیه
قطع استفاده شروع می‌شود. بعد از تخلیهٔ کامل، Shift را رها کنید و اجازه دهید
حداقل ۲۵٪ شارژ شود. هر سکه ۱۰۰ امتیاز دارد و هر گالن ۳۵٪ سوخت برمی‌گرداند.

باز کردن پروژه

نسخهٔ موتور: Unity 2022.3.62f1
رندر: Built-in، همراه Post Processing 3.4
ورودی و رابط: New Input System و TextMeshPro

پروژه را در Unity Hub باز کنید و منتظر دریافت پکیج‌ها بمانید. سپس صحنهٔ
Assets/NightRun/Scenes/NIGHTRUN.unity را اجرا کنید.
مقادیر سرعت، سوخت و نیترو در Assets/NightRun/Resources/RunConfig.asset هستند.
فرمان NIGHTRUN > Rebuild Project صحنه، ورودی‌ها و منابع اصلی را بازسازی می‌کند.

ساخت

ماژول‌های Linux و Windows Mono را از Unity Hub نصب کنید. اگر ادیتور در مسیر
پیش‌فرض Hub نیست، مسیر آن را در UNITY_EDITOR_PATH قرار دهید.

./Tools/build.sh test          آزمون‌های Edit Mode؛ نتیجه در Logs/Validation
./Tools/build.sh qa            خروجی آزمایشی لینوکس
./Tools/build.sh all           خروجی نهایی لینوکس و ویندوز
./Tools/build.sh windows       خروجی نهایی ویندوز
./Tools/build.sh windows-qa    خروجی آزمایشی ویندوز

خروجی ویندوز در Builds/Windows ساخته می‌شود. NIGHTRUN.exe باید همراه
NIGHTRUN_Data، MonoBleedingEdge و UnityPlayer.dll اجرا شود.

فایل‌های تحویل

پوشهٔ محلی delivery فقط برای REPORT.pdf و NIGHTRUN-Setup.exe است و در گیت
قرار نمی‌گیرد. PDF شامل توضیح بازی، ساختار پیاده‌سازی، تصاویر و لینک مخزن است.
نصب‌کننده، همهٔ فایل‌های لازم برای اجرای بازی در ویندوز را همراه دارد و نصب
Unity یا دسترسی مدیر سیستم لازم ندارد.

پس از ساخت خروجی ویندوز، با نصب NSIS و مشخص کردن PDF نهایی:
python3 Tools/package.py --report /path/to/REPORT.pdf

ساختار کد

GameManager وضعیت بازی و رکورد را مدیریت می‌کند. RunModel قوانین بازی و
RunConfig تنظیمات آن را نگه می‌دارند. خودروهای ثابت و متحرک، سکه و سوخت از
Interactable ارث می‌برند. RoadWorld مسیر را بازیافت می‌کند و RoadPlanner
چیدمان ترافیک و دسترسی به لاین‌ها را بررسی می‌کند. جاده، آیتم‌ها، خودروها و
افکت‌ها Pool ثابت دارند. ورودی‌ها از NightRunControls.inputactions خوانده
می‌شوند. رکورد و تنظیمات صدا با PlayerPrefs ذخیره می‌شوند.

منابع و مجوز دارایی‌ها در THIRD_PARTY.txt قرار دارند.
آزمایش محلی تبدیل دارایی‌های Asphalt Nitro در گیت و خروجی عمومی قرار ندارد.
